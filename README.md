A one-page newspaper front page that sums up Friday 20 November 2026's world news in a single image: the UN court ruling that Myanmar committed genocide against the Rohingya, the first US–China–Russia three-way summit in Shenzhen, Ukraine's third strike on the Crimean Bridge in four days, and Anthropic's record $81bn IPO debut — plus a ticker of the day's other big stories. The entry program simply copies the image to the output path, deterministically and with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
